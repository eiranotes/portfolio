# 키스컷 상단 강조 제안

상태: 아이디어 단계. 현재 공개 hero는 변경하지 않음.
목적: 입점·행사 담당자가 첫 화면에서 대표 제품과 그림의 개성을 알아보고 개별 제품으로 들어가게 한다. 원본 sRGB 색, 실제 제품 사진과 기존 이미지 확대 동작 유지.

## 1. 도안을 펼쳐 놓은 첫 화면 — 추천

상단에 브랜드 소개 1–2줄, 바로 아래 V1/V2에서 골라낸 세로형 이미지 5–6장. V1의 과일·보태니컬·바다와 V2의 우주 유영·달토끼 춤·바다의 이야기를 섞어 따뜻한 색에서 깊은 파랑까지 이어준다. 이미지 크기를 충분히 확보하고 얕은 높이 차이만 준다. 각 이미지는 확대 및 해당 컬렉션으로 연결한다.

데스크톱은 한눈에 5–6개, 모바일은 2개와 다음 이미지 일부가 보이는 수동 가로 넘김. 자동 흘림 없음. 다음 구간에 V1/V2 실물 사진을 함께 놓아 투명 소재와 후가공을 보여준다. 개별 상품 이미지가 실제로 길게 펼친 도안인지 검수 후 크롭 범위 결정; 도안을 자르지 않고 원본 비율 우선.

카피 후보: ‘작은 장면을, 길게 간직하는 방법.’ / ‘아델리드로우의 스테인드글라스 키스컷’.

## 2. V1·V2 실물 사진을 양쪽으로

확보된 collection-v1 / stained-glass-v2 사진 2장을 첫 화면의 대부분에 배치. 두 사진 모두 테이프를 펼친 상태와 롤이 보여 상품 이해가 가장 빠르다. 하단의 작은 개별 이미지 목록을 선택하면 큰 제품 이미지를 바꾸는 방식. 모바일은 사진 1장씩 수동 넘김, V1/V2 선택은 항상 표시.

장점: 바이어에게 인쇄·후가공 품질이 즉시 전달됨. 한계: 첫 화면에 모든 개별 도안을 동일한 크기로 보여주기 어려움.

## 3. 큰 한 장과 작은 작품 목록

대표 도안 한 장을 크게, 아래에 V1 6종 / V2 5종의 개별 이미지 목록. 선택하면 큰 이미지·작품명·실물 사진이 함께 바뀐다. 모바일에서도 큰 그림 한 장을 충분히 감상할 수 있다.

장점: 개별 작품 감상에 적합. 한계: 사용자가 누르지 않으면 첫 작품만 강하게 기억하므로 이번 ‘한눈에 다양성’ 목적에는 1안보다 약함.

추천 조합: 1안 첫 화면 + 2안의 실물 사진 구간. 원화 작품 섹션은 이어서 남기고, 과도한 카드/판매 숫자/장식 배지 없이 제품 이미지 자체로 강조한다.
