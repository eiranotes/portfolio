## 2026-09-14 · 연락처와 상세 약력

키스컷 상단은 이번 요청의 아이디어 범위로 유지. 약력은 행사 CSV와 추가 활동 JSON을 기준으로 생성하며 최근 6건을 노출하고 이전 행사·상세 활동은 native details로 제공. 이메일은 사용자 직접 지정 우선. SNS 아카이브의 콜라보는 공지 사실로 표현, 성과/출시 완료 주장 없음. 젤리크루는 과거 판매 이력. 검색 결과의 관련 없는 작가 RT나 사업자 등록연도는 사용하지 않음. 이미지 변경 없는 콘텐츠 수정은 build.py --html-only로 기존 색상관리 파생본 재사용.


## 키스컷 첫 화면 1안

사용자가 1안 선택. 제품 안내 이미지 원본 4:5 전체 비율을 사용하며 색상/크롭 수정 없음. 데스크톱 6종, 모바일 두 장과 다음 이미지 일부를 보여 수동 넘김 유도. 자동 재생 없이 CSS scroll-snap 사용, 각 도안은 기존 dialog로 확대, V1/V2 캡션은 대응 실물 컬렉션 앵커. 실물 컬렉션은 한 번만 노출하고 원화/제품/약력/연락처로 이어짐.


## 2026-09-14 · 키스컷 조각 창

첫 화면은 제품 사진의 나열이 아니라 키스컷 조각 자체로 시리즈를 표현한다. 아델리페이지 디지털 스티커팩과 같은 칼선 분리 방식(build_kisscut_packs.from_cut)을 읽기 전용으로 재사용해 V1 6종을 새로 분리하고 V2 5종도 같은 스케일로 다시 분리했다(공개된 V2 팩과 개수 동일 9/10/11/11/6). 모든 테이프의 렌더 스케일이 같으므로 조각의 실제 상대 크기를 그대로 사용하고, CSS grid dense 자동 배치로 한 판을 채운다(데스크톱 0.38 css px/원본 px, 셀 24px). 조각 위치는 브라우저가 결정하므로 테이프별로 완전히 묶이지 않으며, 범례 스포트라이트가 테이프 소속을 드러낸다. V1은 따뜻한 종이색, V2는 제품 도안 배경과 같은 남색 판. 그라디언트·그림자·회전·자동 재생 없음.

조각 파생본은 알파가 필요해 lossy WebP q88(총 2.5 MiB)로 생성한다. 원화·제품 사진의 무손실 규칙 예외이며 원본 해상도(최대 433px)를 넘지 않고, 확대 보기는 1.6배까지만 키운다. 파생본은 site/kisscut-manifest.json으로 관리하고 --html-only에서도 매니페스트가 없으면 생성한다. 이전 6장 히어로(1안)는 제거했으며 실물 컬렉션 구간과 앵커는 유지.


## 2026-09-14 · 대표작 소개 구조와 색 보정

첫 화면은 "대표작 설명 → 작품 소개" 순서로, 조각을 전부 나열하지 않고 테이프당 3조각을 골라 제목과 묘사 캡션을 붙인다. 캡션은 그림에 보이는 것을 적은 묘사형이며 공식 제목이 아니다. 사양 문구는 브랜드 제품 안내 이미지의 "PET / 오로라 금박(은박) 가공 / 40mm(30mm) x 5m"만 사용한다.

CMYK PSD의 색 변환은 원화와 같은 ICC relative colorimetric 규칙을 따른다. 프로파일이 없는 V2 PSD는 같은 작업자의 V1 파일이 모두 Japan Color 2001 Coated이므로 동일 프로파일을 가정하되, 미태깅 CMYK를 조용히 변환하지 않는다는 기존 규칙에 맞춰 가정 사실을 sources/kisscut-stickers.json과 문서에 명시한다. 원본 작업 프로파일이 확인되면 extract_kisscut.py의 FALLBACK만 바꿔 재생성한다. 조각의 상대 크기는 유지하되 폭이 좁은 화면에서는 같은 비율로 축소한다(flex shrink).
